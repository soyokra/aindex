
### 1. 基础连接与形状 (Shapes & Connections)
这是最简单的入门，展示了如何定义节点、自定义标签和选择形状。

```d2
# 定义形状和标签
pg: PostgreSQL
Cloud: my-cloud {
  shape: cloud
}

# 连接方式
pg -> Cloud: 同步数据
Cloud <- pg: 反向读取
pg <-> Cloud: 双向同步

# 形状目录 (部分)
db: {shape: cylinder}
user: {shape: person}
decision: {shape: diamond}
queue: {shape: queue}
```

### 2. 容器与嵌套 (Containers & Nesting)
D2 的杀手锏是极其自然的嵌套语法，非常适合描述系统层级。

```d2
# 方式 A: 缩进嵌套
High Level Service: {
  API Gateway -> Auth Service
  Auth Service -> Database
}

# 方式 B: 点号引用 (外链嵌套)
Network.Firewall -> Network.InternalServer
Network: {
  Firewall
  InternalServer
}

# 引用父级 ( _ 表示父级)
Outside -> Inside.Child
Inside: {
  Child -> _.Outside
}
```

### 3. 样式与主题 (Styling & Classes)
D2 支持精细的样式控制，甚至可以像 CSS 一样定义类。

```d2
# 定义可复用的类
classes: {
  critical: {
    style: {
      fill: "red"
      font-color: "white"
      stroke-width: 4
    }
  }
}

# 应用样式和类
Alert System: {
  class: critical
  style: {
    stroke-dash: 5  # 虚线
    3d: true        # 3D 效果
  }
}

# 连接线样式
A -> B: 重要的线 {
  style: {
    stroke: "blue"
    animated: true  # 动画效果 (SVG 支持)
  }
}
```

### 4. 特殊形状：SQL 表、类图与 Markdown
D2 可以直接渲染结构化数据，这对 Java/Spring 开发者非常友好。

```d2
# SQL 表结构
users: {
  shape: sql_table
  id: int {constraint: primary_key}
  username: varchar(50)
  email: varchar(255) {constraint: unique}
}

# 类图 (UML)
OrderService: {
  shape: class
  method1(): void
  method2(param: string): int
  field1: string
}

# Markdown 支持
Documentation: |md
  ### 业务逻辑说明
  1. 接收订单
  2. 校验库存
  3. **完成支付**
|
```

### 5. 交互与布局配置 (Interactivity & Config)
你可以配置全局渲染属性，甚至添加交互链接。

```d2
direction: right # 布局方向: right, left, up, down

vars: {
  d2-config: {
    layout-engine: dagre # 也可以选 elk 或 tala (收费)
    theme-id: 200        # 主题 ID
  }
}

# 交互链接
Google: {
  link: "https://www.google.com"
  tooltip: "点击访问谷歌"
}
```

### 6. 综合实战：典型后端架构
将上述语法整合，模拟一个你熟悉的 **Spec-Driven** 工作流：

```d2
direction: down

User -> Gateway: REST API

Gateway: {
  shape: package
  style.fill: "#f5f5f5"
  
  Auth: {shape: circle}
  RateLimit: {shape: hexagon}
  
  Auth -> RateLimit
}

Gateway.RateLimit -> BusinessLogic: 校验通过

BusinessLogic: {
  class: important_node
  OrderService -> InventoryService
  OrderService -> DB.Orders
}

DB: {
  shape: cylinder
  Orders: {shape: sql_table}
}

classes: {
  important_node: {
    style: {
      double-border: true
      border-radius: 10
    }
  }
}
```
